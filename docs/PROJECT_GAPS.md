## 本次四项收尾状态

### 1. 统一敏感策略：已实现

敏感金额、商品分组和日期维度禁止用于派生统计。页面、计划校验和真实工具调用共用该规则，
报告也过滤对应统计。三种问答路径在发送模型前处理问题中的已标记敏感取值和常见个人信息。
管理员仍可审核原始预览/导出；这不授权把原始行发送给模型。

### 2. 显式风险评估：已实现

计划校验时生成可展示的风险等级、触发原因与步骤说明，
实际工具调用前按同样规则再检查。
例如：普通汇总为低风险；管理员预览已标记的邮箱列、导出全部原始数据需审核；
分析员请求这些操作直接拒绝。是否允许执行仍由代码决定。

新增检查覆盖敏感字段派生统计、三种问答输入脱敏、管理员高风险审核与分析员越权拒绝。
即使直接调用 Agent 跳过计划校验，执行前的守卫仍阻止不允许的工具。
调用者未启用审核机制时，高风险工具也不能直接运行。

### 3. Trace 步骤展示：已实现

历史记录现在按发生顺序展示步骤，新增受控工具结果摘要、脱敏的最终回答和风险原因。
摘要只提取白名单字段；预览行、CSV 内容和未知结果字段不写入日志。

这种历史展示无需重新调用模型或再次执行导出。若要“重新执行旧问题”，
还涉及数据版本、重复操作与模型非确定性，不是当前简历演示的必要前置条件。
历史事件缺少的字段应显示“旧记录未保存”，不能补造。

页面保留旧日志兼容与账户隔离，查看过程只读取日志。完整验证结果见 [进度记录](../PROGRESS.md)。

### 4. 真实操作验收：尚未完成

已尝试恢复真实浏览器验收，但 Windows Computer Use 因无法可靠确认浏览器 URL 而停止。
临时服务随后结束，用户反馈“拒绝连接”；该临时服务的独立后台启动被自动审批拒绝。
用户再次明确要求启动项目后，正式项目已成功后台启动，健康接口返回 HTTP 200 / `ok`。
仍需实际保存报告和已批准 CSV，并在用户终端运行的服务上按 Ctrl+C 确认关闭。
自动化接口及单元测试结果不能替代这些实际操作。

演示前应记录真实千问调用是否成功、实际步骤与预期数值是否一致。
模型调用顺序可能变化，不能预先伪造一条“必然成功”的执行记录。

## 哪些是可选扩展

- **图表嵌入报告**：当前 Markdown 导出已满足“报告导出”的基础目标；
  图文 HTML/PDF 或图片打包下载可在有明确需求时增加。
- **严格按计划执行**：当前目标已经有计划和多步工具调用；若要求每一步都
  与批准的计划一致，再增加计划与实际调用的一致性校验。
- **格式成功率评测**：若简历要写具体提升比例，先建立固定问题集、失败分类、
  对照提示词、模型版本与重复次数，再运行真实评测并记录结果。
- **公网和企业化**：需要先确认实际部署环境和使用需求。一个“企业级”形容词
  不能用再加几个功能代替生产验证；用于求职可称“面向运营数据分析的多用户项目”。
